# Изображения BLACKLINE

Все четыре изображения созданы специально для демонстрационного проекта встроенным инструментом OpenAI ImageGen. Это синтетические иллюстрации, а не фотографии существующей студии и не подтверждение выполненных BLACKLINE работ. На сайте сохранены соответствующие подписи. Внешние фотобанки и изображения реальных студий не использованы.

Файлы подключены локально, интернет для их загрузки не требуется:

- `hero.png` — графитовый автомобиль в тёмной студии, горизонтальная композиция.
- `polishing.png` — машинная полировка кузова.
- `interior.png` — очистка кожаного салона кистью.
- `ceramic.png` — нанесение покрытия аппликатором.

Краткий набор промптов: фотореалистичная премиальная автомобильная съёмка; вымышленная тёмная студия; профессиональный мягкий свет и отражения; без логотипов и надписей. Для первого экрана — автомобиль справа и тёмное пространство слева для текста. Для галереи — квадратные крупные планы полировки машинкой, очистки коричневого кожаного сиденья и нанесения керамики рукой в чёрной перчатке.

Изображения можно заменить своими файлами с теми же именами. Используйте материалы, на которые у вас есть права; обновите подписи об ИИ, если замените изображения настоящими фотографиями.
